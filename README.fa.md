# AS-LMS — سامانه مدیریت یادگیری

AS-LMS یک سامانه مدیریت یادگیری دسکتاپ است که با Python، Tkinter و MySQL توسعه داده شده است. این برنامه رابط‌های جداگانه‌ای برای مدیران، مدرسان و دانشجویان فراهم می‌کند تا دوره‌ها، تکالیف، ارسال پاسخ‌ها، نمرات و بازخوردهای آموزشی را مدیریت کنند.

## امکانات

### مدیر سیستم
- مدیریت حساب‌های کاربری و نقش‌ها.
- مدیریت دوره‌ها و ثبت‌نام دانشجویان در دوره‌ها.
- تعیین ارتباطات آموزشی مناسب میان مدرسان و دانشجویان.
- مدیریت ارتباط استاد راهنما و دانشجو.

### مدرس
- دسترسی به رابط کاربری مدرس.
- مدیریت تکالیف دوره‌ها.
- تعیین توضیحات تکلیف، حداکثر نمره و مهلت تحویل.
- بررسی پاسخ‌های ارسال‌شده توسط دانشجویان.
- نمره‌دهی به تکالیف و ارائه بازخورد.

### دانشجو
- دسترسی به دوره‌هایی که در آن‌ها ثبت‌نام کرده و تکالیف اختصاص‌یافته.
- مشاهده جزئیات تکالیف و مهلت تحویل.
- ارسال پاسخ تکالیف.
- مشاهده نمرات و بازخوردهای مدرس.

## فناوری‌های استفاده‌شده

- **زبان برنامه‌نویسی:** Python
- **رابط گرافیکی:** Tkinter و ttk
- **پایگاه داده:** MySQL
- **درایور اتصال به پایگاه داده:** MySQL Connector/Python
- **هش‌کردن رمز عبور:** SHA-256 در پیاده‌سازی فعلی

## پیش‌نیازها

- Windows 10 یا Windows 11
- Python نسخه 3.10 یا نسخه سازگار
- MySQL Server
- pip

## ساختار پروژه

ساختار زیر یک نمونه از ساختار پروژه است و ممکن است فایل‌های موجود در مخزن واقعی با آن تفاوت داشته باشند.

```text
AS-LMS/
├── main.py
├── view.py
├── controller.py
├── model.py
├── style.py
├── requirements.txt
├── .gitignore
├── .env.example
├── help.txt
├── database/
│   ├── schema.sql
│   └── seed.sql
└── README.md
```

## نصب و راه‌اندازی

### ۱. دریافت پروژه

مخزن را کلون کنید:

```bash
git clone https://github.com/ArshamScode/AS-LMS.git
cd AS-LMS
```

همچنین می‌توانید در GitHub گزینه **Code → Download ZIP** را انتخاب کنید و فایل دانلودشده را از حالت فشرده خارج کنید.

### ۲. ایجاد محیط مجازی

```bash
python -m venv .venv
```

فعال‌سازی محیط مجازی در ویندوز:

```bat
.venv\Scripts\activate
```

### ۳. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### ۴. پیکربندی MySQL

مطمئن شوید که MySQL Server نصب شده و در حال اجرا است.

میزبان، پورت، نام کاربری، رمز عبور و نام پایگاه داده را مطابق تنظیمات محلی MySQL خود پیکربندی کنید. تنظیمات اتصال پایگاه داده برنامه معمولاً در فایل `model.py` قرار دارد.

رمزهای عبور واقعی پایگاه داده یا اطلاعات محرمانه را در مخزن عمومی منتشر نکنید.

### ۵. ایجاد جداول پایگاه داده

اگر فایل `database/schema.sql` در مخزن وجود دارد، آن را در MySQL Workbench یا یک ابزار دیگر مدیریت MySQL اجرا کنید تا ساختار پایگاه داده ایجاد شود.

پیش از اجرای فایل SQL، محتوای آن را بررسی کنید. مطمئن شوید پایگاه داده‌ای که اطلاعات مهمی در آن دارید حذف یا بازنویسی نمی‌شود.

### ۶. افزودن داده‌های آزمایشی

اگر فایل `database/seed.sql` در مخزن وجود دارد، پس از ایجاد ساختار پایگاه داده آن را اجرا کنید تا داده‌های آزمایشی وارد شوند.

فایل داده‌های آزمایشی را فقط در شرایط مناسب اجرا کنید. اگر اسکریپت برای اجرای تکراری طراحی نشده باشد، اجرای چندباره آن ممکن است باعث ایجاد رکوردهای تکراری یا مشکلات دیگر شود.

### ۷. اجرای برنامه

در پوشه اصلی پروژه اجرا کنید:

```bash
python main.py
```

## اطلاعات ورود آزمایشی

حساب‌های زیر برای آزمایش محلی مستند شده‌اند. این حساب‌ها تنها زمانی کار می‌کنند که رکوردهای کاربری و هش‌های رمز عبور متناظر در پایگاه داده ایجاد شده باشند.

**رمز عبور آزمایشی:** `password123`

| نقش | نام کاربری | رمز عبور |
|---|---|---|
| مدیر سیستم | `admin` | `password123` |
| مدرس | `teacher1` | `password123` |
| دانشجو | `student1` | `password123` |
| دانشجو | `student2` | `password123` |

این حساب‌ها فقط برای آزمایش و نمایش محلی هستند. از رمز عبور نمونه برای حساب‌های واقعی یا اطلاعات حساس استفاده نکنید.

## پایگاه داده

پایگاه داده برای پشتیبانی از گردش‌کارهای سامانه مدیریت یادگیری طراحی شده و شامل بخش‌هایی مانند موارد زیر است:

- کاربران و نقش‌ها
- ارتباط استاد راهنما و دانشجو
- دوره‌ها و ثبت‌نام‌ها
- تکالیف و تخصیص تکالیف
- پاسخ‌های ارسال‌شده توسط دانشجویان
- نمرات و بازخوردها

برای مشاهده ساختار واقعی پایگاه داده و داده‌های آزمایشی موجود، فایل‌های SQL داخل مخزن را بررسی کنید.

## نکات امنیتی

- حساب‌های آزمایشی از یک رمز عبور نمونه مشترک استفاده می‌کنند.
- پیاده‌سازی فعلی برای هش‌کردن رمز عبور از SHA-256 استفاده می‌کند. استفاده از SHA-256 به‌تنهایی برای ذخیره رمزهای عبور در برنامه‌های عملیاتی توصیه نمی‌شود. از الگوریتم‌های مخصوص ذخیره رمز عبور مانند Argon2id، scrypt یا bcrypt با تنظیمات مناسب استفاده کنید.
- اطلاعات اتصال MySQL خود را به‌صورت محلی تنظیم کنید.
- رمزهای عبور واقعی، کلیدهای API، فایل‌های پیکربندی خصوصی یا اطلاعات حساس کاربران را در مخزن عمومی قرار ندهید.
- پیش از اجرای اسکریپت‌های SQL، به‌ویژه اسکریپت‌هایی که پایگاه داده یا جدول‌ها را ایجاد، حذف یا بازنویسی می‌کنند، آن‌ها را بررسی کنید.
- پیش از استفاده از برنامه برای کاربران واقعی یا داده‌های عملیاتی، آن را بررسی و آزمایش کنید.

## عیب‌یابی

**خطا در اتصال به MySQL**
- مطمئن شوید MySQL Server در حال اجرا است.
- میزبان، پورت، نام کاربری و رمز عبور تنظیم‌شده در برنامه را بررسی کنید.
- از ایجاد پایگاه داده و جدول‌های موردنیاز اطمینان حاصل کنید.

**ماژول پایتون پیدا نمی‌شود**
- محیط مجازی را فعال کنید.
- دوباره دستور `pip install -r requirements.txt` را اجرا کنید.
- مطمئن شوید وابستگی‌های موردنیاز برنامه در `requirements.txt` درج شده‌اند.

**ورود آزمایشی کار نمی‌کند**
- بررسی کنید رکوردهای حساب‌های آزمایشی در پایگاه داده وجود داشته باشند.
- مطمئن شوید برنامه به همان پایگاه داده‌ای متصل است که این رکوردها در آن قرار دارند.
- بررسی کنید منطق هش‌کردن رمز عبور با هش‌های ذخیره‌شده در پایگاه داده سازگار باشد.
