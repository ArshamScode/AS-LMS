# AS LMS — سامانهٔ مدیریت آموزش

یک برنامهٔ دسکتاپ با Python برای مدیریت دوره‌های آموزشی، تکالیف و پیشرفت دانش‌آموزان.

## معرفی پروژه

**AS LMS** یک سامانهٔ مدیریت آموزش مبتنی بر رابط گرافیکی است که با Python، کتابخانهٔ Tkinter و پایگاه دادهٔ MySQL ساخته شده است. برنامه برای سه نقش مدیر، معلم و دانش‌آموز رابط‌های جداگانه دارد.

## امکانات

* **پنل مدیر:** مدیریت کاربران، دوره‌ها، ثبت‌نام‌ها و ارتباط معلم و دانش‌آموز.
* **پنل معلم:** مدیریت تکالیف، تعیین مهلت و نمره، بررسی پاسخ‌ها و ارائهٔ بازخورد.
* **پنل دانش‌آموز:** مشاهدهٔ تکالیف، ارسال پاسخ یا فایل و بررسی نمره‌ها و بازخوردها.
* **پایگاه دادهٔ MySQL:** ذخیرهٔ اطلاعات برنامه در پایگاه دادهٔ رابطه‌ای.
* **رابط دسکتاپ:** رابط گرافیکی ساخته‌شده با Tkinter و ttk.

## فناوری‌ها

* Python
* Tkinter / ttk
* MySQL
* MySQL Connector/Python

## پیش‌نیازها

* Python 3
* MySQL Server
* وابستگی‌های Python موردنیاز پروژه

## راه‌اندازی

۱. Python و MySQL Server را نصب کنید.

۲. پایگاه دادهٔ برنامه را ایجاد و تنظیم کنید.

۳. وابستگی‌های موردنیاز Python را نصب کنید.

۴. تنظیمات اتصال به پایگاه داده را مطابق محیط محلی خود انجام دهید.

۵. برنامه را با دستور زیر اجرا کنید:

```bash
python main.py
```

جزئیات نصب و تنظیم پایگاه داده در ادامهٔ آماده‌سازی پروژه تکمیل خواهد شد.

## نکات امنیتی

این پروژه برای یادگیری و توسعهٔ نرم‌افزار در نظر گرفته شده است. پیش از استفاده با کاربران واقعی یا داده‌های حساس، مدیریت اعتبارنامه‌ها، شیوهٔ ذخیرهٔ رمز عبور، مجوزهای پایگاه داده و کنترل دسترسی نقش‌ها را بررسی کنید.

هرگز رمزهای واقعی، کلیدهای API، اطلاعات خصوصی کاربران یا فایل `.env` محلی را در مخزن عمومی منتشر نکنید.
