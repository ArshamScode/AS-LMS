# AS-LMS — سامانه مدیریت یادگیری

**AS-LMS** یک نرم‌افزار دسکتاپ برای مدیریت فرایندهای آموزشی است که با Python، رابط گرافیکی Tkinter و پایگاه داده MySQL توسعه داده شده است.

این برنامه برای سه گروه کاربری مدیر، مدرس و دانشجو رابط‌های جداگانه ارائه می‌دهد و امکاناتی برای مدیریت کاربران، دوره‌ها، تکالیف، ارسال تمرین‌ها، نمره‌دهی و ارائه بازخورد دارد.

## امکانات پروژه

### مدیر سیستم
- مدیریت حساب‌های کاربری و نقش‌ها
- مدیریت دوره‌های آموزشی
- مدیریت ثبت‌نام دانشجویان در دوره‌ها
- مدیریت ارتباط بین دانشجویان و مدرسان مشاور

### مدرس
- دسترسی به محیط کاربری مدرس
- مدیریت تکالیف دوره‌ها
- تعیین توضیحات، حداکثر نمره و مهلت انجام تکالیف
- بررسی تمرین‌های ارسال‌شده توسط دانشجویان
- ثبت نمره و ارائه بازخورد آموزشی

### دانشجو
- مشاهده دوره‌های ثبت‌نام‌شده و تکالیف اختصاص‌یافته
- مشاهده جزئیات و مهلت انجام تکالیف
- ارسال پاسخ یا محتوای تمرین
- مشاهده نمرات و بازخوردهای مدرس

## فناوری‌های استفاده‌شده

- **زبان برنامه‌نویسی:** Python
- **رابط گرافیکی:** Tkinter و ttk
- **پایگاه داده:** MySQL
- **اتصال به پایگاه داده:** MySQL Connector/Python
- **هش رمز عبور:** SHA-256

## پیش‌نیازها

- Windows 10 یا Windows 11
- Python نسخه 3.10 یا نسخه سازگار
- MySQL Server
- pip

## نصب و راه‌اندازی

### ۱. دریافت پروژه

مخزن را با دستور زیر دریافت کنید:

```bash
git clone https://github.com/ArshamScode/AS-LMS.git
cd AS-LMS
```

همچنین می‌توانید از GitHub گزینه **Code → Download ZIP** را انتخاب کرده و فایل فشرده را استخراج کنید.

### ۲. ساخت محیط مجازی Python

```bash
python -m venv .venv
```

فعال‌سازی محیط مجازی در ویندوز:

```bash
.venv\Scripts\activate
```

### ۳. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### ۴. تنظیم اتصال MySQL

مطمئن شوید MySQL Server نصب شده و در حال اجرا است.

تنظیمات اتصال پایگاه داده در برنامه، معمولاً در فایل `model.py`، را بررسی کنید. نام کاربری، رمز عبور، میزبان، پورت و نام پایگاه داده باید با تنظیمات محلی MySQL شما مطابقت داشته باشند.

رمزهای واقعی و اطلاعات محرمانه خود را در مخزن عمومی منتشر نکنید.

### ۵. ایجاد ساختار پایگاه داده

فایل زیر را در MySQL Workbench یا ابزار مشابه اجرا کنید:

```text
database/schema.sql
```

این فایل پایگاه داده و جدول‌های موردنیاز برنامه را ایجاد می‌کند و برای حذف عمدی پایگاه داده موجود طراحی نشده است.

### ۶. افزودن اطلاعات آزمایشی

پس از ایجاد جدول‌ها، فایل زیر را اجرا کنید:

```text
database/seed.sql
```

این فایل حساب‌های آزمایشی، یک دوره آموزشی، ثبت‌نام‌ها و یک تکلیف نمونه را ایجاد می‌کند.

بهتر است فایل seed را فقط یک‌بار روی پایگاه داده آزمایشی تازه اجرا کنید؛ اجرای مجدد آن ممکن است به دلیل تکراری بودن اطلاعات با خطا مواجه شود.

### ۷. اجرای برنامه

در پوشه اصلی پروژه اجرا کنید:

```bash
python main.py
```

## اطلاعات ورود حساب‌های آزمایشی

در صورتی که فایل `database/seed.sql` با موفقیت اجرا شده باشد، می‌توانید از حساب‌های زیر استفاده کنید.

**رمز عبور تمام حساب‌های آزمایشی:** `password123`

| نقش | نام کاربری | رمز عبور |
|---|---|---|
| مدیر سیستم | `admin` | `password123` |
| مدرس | `teacher1` | `password123` |
| دانشجو | `student1` | `password123` |
| دانشجو | `student2` | `password123` |

این حساب‌ها فقط برای آزمایش و نمایش امکانات برنامه هستند. از این رمز برای حساب‌های واقعی یا اطلاعات حساس استفاده نکنید.

## ساختار پایگاه داده

پایگاه داده شامل جدول‌هایی برای مدیریت موارد زیر است:

- کاربران و نقش‌ها
- ارتباط دانشجویان و مدرسان مشاور
- دوره‌های آموزشی و ثبت‌نام‌ها
- تکالیف و تخصیص آن‌ها به دانشجویان
- پاسخ‌ها و تمرین‌های ارسالی
- نمرات و بازخوردهای آموزشی

فایل‌های SQL جداگانه ارائه شده‌اند تا کاربران بتوانند ساختار پایگاه داده را ایجاد کنند و در صورت نیاز اطلاعات آزمایشی را نیز وارد کنند.

## نکات امنیتی

- حساب‌های نمونه از یک رمز مشترک و آزمایشی استفاده می‌کنند.
- نسخه فعلی پروژه برای هش رمز عبور از SHA-256 استفاده می‌کند. برای نرم‌افزارهای عملیاتی، استفاده از الگوریتم‌های مخصوص ذخیره امن رمز عبور مانند Argon2id، scrypt یا bcrypt توصیه می‌شود.
- اطلاعات اتصال MySQL خود را به‌صورت محلی تنظیم کنید.
- رمزهای واقعی، کلیدهای API، فایل‌های پیکربندی محرمانه و اطلاعات حساس کاربران را در مخزن عمومی قرار ندهید.
- پیش از استفاده با کاربران واقعی یا داده‌های عملیاتی، پروژه را بررسی و آزمایش کنید.

## رفع مشکلات رایج

**خطا در اتصال به MySQL**
- بررسی کنید MySQL Server در حال اجرا باشد.
- میزبان، پورت، نام کاربری و رمز عبور را بررسی کنید.
- مطمئن شوید پایگاه داده با موفقیت ایجاد شده است.

**خطای نبودن ماژول Python**
- محیط مجازی را فعال کنید.
- دستور `pip install -r requirements.txt` را دوباره اجرا کنید.

**عدم ورود با حساب آزمایشی**
- مطمئن شوید فایل `database/seed.sql` بدون خطا اجرا شده است.
- بررسی کنید برنامه و فایل seed به یک پایگاه داده متصل باشند.
- مطمئن شوید روش هش رمز عبور با هش ذخیره‌شده در پایگاه داده مطابقت دارد.
