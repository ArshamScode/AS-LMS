# AS LMS — 学习管理系统

一个使用 Python 开发的桌面应用程序，用于管理课程、作业和学生学习进度。

## 项目简介

**AS LMS** 是一款基于 Python、Tkinter 和 MySQL 的桌面学习管理系统，为管理员、教师和学生提供不同的操作界面。

## 功能特点

* **管理员面板：** 管理用户、课程、选课信息以及教师与学生之间的关联。
* **教师面板：** 管理作业、设置截止日期和成绩、审核提交内容并提供反馈。
* **学生面板：** 查看作业、提交文本或文件，并查看成绩和教师反馈。
* **MySQL 数据库：** 使用关系型数据库存储应用程序数据。
* **桌面图形界面：** 使用 Tkinter 和 ttk 构建。

## 技术栈

* Python
* Tkinter / ttk
* MySQL
* MySQL Connector/Python

## 运行要求

* Python 3
* MySQL Server
* 项目运行所需的 Python 依赖包

## 安装与运行

1. 安装 Python 和 MySQL Server。
2. 创建应用程序数据库并配置连接信息。
3. 安装所需的 Python 依赖包。
4. 根据本地环境配置数据库连接。
5. 使用以下命令运行程序：

```bash
python main.py
```

数据库初始化和详细配置说明将在后续项目文档中完善。

## 安全说明

本项目主要用于学习和开发。在处理真实用户或敏感数据之前，请检查数据库权限、凭据管理、密码存储方式以及基于角色的访问控制。

请勿将真实密码、API 密钥、私人用户数据或本地 `.env` 文件提交到公开仓库。
