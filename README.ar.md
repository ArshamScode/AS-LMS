# AS-LMS — نظام إدارة التعلّم

AS-LMS هو نظام لإدارة التعلّم يعمل كتطبيق سطح مكتب، وقد تم تطويره باستخدام Python وTkinter وMySQL. يوفر النظام واجهات منفصلة للمسؤولين والمدرّسين والطلاب لإدارة المقررات والواجبات والتسليمات والدرجات والملاحظات الأكاديمية.

## الميزات

### المسؤول
- إدارة حسابات المستخدمين وأدوارهم.
- إدارة المقررات والتسجيل فيها.
- ربط المدرّسين والطلاب بالعلاقات الأكاديمية المناسبة.
- إدارة علاقات الإرشاد الأكاديمي بين المدرّسين والطلاب.

### المدرّس
- الوصول إلى واجهة المدرّس.
- إدارة واجبات المقررات.
- تحديد وصف الواجب والدرجة القصوى والموعد النهائي.
- مراجعة تسليمات الطلاب.
- تصحيح الأعمال المقدّمة وتقديم الملاحظات.

### الطالب
- الوصول إلى المقررات المسجّل فيها والواجبات المكلّف بها.
- عرض تفاصيل الواجبات ومواعيد التسليم.
- إرسال إجابات الواجبات.
- الاطلاع على الدرجات وملاحظات المدرّس.

## التقنيات المستخدمة

- **لغة البرمجة:** Python
- **واجهة المستخدم الرسومية:** Tkinter وttk
- **قاعدة البيانات:** MySQL
- **موصل قاعدة البيانات:** MySQL Connector/Python
- **تجزئة كلمات المرور:** SHA-256 في التنفيذ الحالي

## المتطلبات

- Windows 10 أو Windows 11
- Python 3.10 أو إصدار متوافق
- MySQL Server
- pip

## التثبيت والإعداد

### 1. تنزيل المشروع

استنسخ المستودع:

```bash
git clone https://github.com/ArshamScode/AS-LMS.git
cd AS-LMS
```

يمكنك أيضًا اختيار **Code → Download ZIP** من GitHub ثم فك ضغط الملف الذي تم تنزيله.

### 2. إنشاء بيئة افتراضية

```bash
python -m venv .venv
```

لتفعيل البيئة الافتراضية على Windows:

```bat
.venv\Scripts\activate
```

### 3. تثبيت الاعتماديات

```bash
pip install -r requirements.txt
```

### 4. إعداد MySQL

تأكد من تثبيت MySQL Server وتشغيله.

اضبط مضيف قاعدة البيانات والمنفذ واسم المستخدم وكلمة المرور واسم قاعدة البيانات بما يتوافق مع إعدادات MySQL المحلية لديك. راجع إعدادات اتصال قاعدة البيانات المستخدمة في التطبيق، والتي توجد عادةً في `model.py`.

لا ترفع كلمات مرور قاعدة البيانات الحقيقية أو أي بيانات اعتماد خاصة إلى المستودع العام.

### 5. إنشاء جداول قاعدة البيانات

إذا كان الملف `database/schema.sql` موجودًا في المستودع، فافتح MySQL Workbench أو أي أداة أخرى لإدارة MySQL ونفّذ الملف لإنشاء بنية قاعدة البيانات.

راجع محتوى ملف SQL قبل تشغيله، وتأكد من أنه لن يحذف قاعدة بيانات تحتوي على بيانات تريد الاحتفاظ بها أو يستبدلها.

### 6. إضافة البيانات التجريبية

إذا كان الملف `database/seed.sql` موجودًا في المستودع، فنفّذه بعد إنشاء بنية قاعدة البيانات لإضافة البيانات التجريبية.

شغّل ملف البيانات التجريبية عند الحاجة فقط. إذا لم يكن مصممًا للتشغيل المتكرر، فقد يؤدي تشغيله عدة مرات إلى إنشاء سجلات مكررة أو مشكلات أخرى في قاعدة البيانات.

### 7. تشغيل التطبيق

من مجلد المشروع، نفّذ:

```bash
python main.py
```

## بيانات تسجيل الدخول التجريبية

الحسابات التالية موثقة للاختبار المحلي. لن تعمل إلا إذا كانت سجلات الحسابات وتجزئات كلمات المرور المطابقة موجودة في قاعدة البيانات.

**كلمة المرور التجريبية:** `password123`

| الدور | اسم المستخدم | كلمة المرور |
|---|---|---|
| المسؤول | `admin` | `password123` |
| المدرّس | `teacher1` | `password123` |
| الطالب | `student1` | `password123` |
| الطالب | `student2` | `password123` |

هذه الحسابات مخصصة للاختبار والعرض محليًا فقط. لا تستخدم كلمة المرور التجريبية لحسابات حقيقية أو للتعامل مع معلومات حساسة.

## قاعدة البيانات

صُممت قاعدة البيانات لدعم وظائف نظام إدارة التعلّم، بما في ذلك:

- المستخدمون والأدوار
- علاقات الإرشاد الأكاديمي بين المدرّسين والطلاب
- المقررات والتسجيلات
- الواجبات وتوزيعها
- تسليمات الطلاب
- الدرجات والملاحظات

راجع ملفات SQL الموجودة في المستودع للاطلاع على بنية قاعدة البيانات الفعلية وأي بيانات تجريبية متاحة.

## ملاحظات أمنية

- تستخدم الحسابات التجريبية كلمة مرور نموذجية مشتركة.
- يستخدم التنفيذ الحالي SHA-256 لتجزئة كلمات المرور. لا يُنصح باستخدام SHA-256 وحده لتخزين كلمات المرور في التطبيقات الإنتاجية. استخدم خوارزمية مصممة لتخزين كلمات المرور، مثل Argon2id أو scrypt أو bcrypt، مع إعدادات مناسبة.
- اضبط بيانات اتصال MySQL الخاصة بك محليًا.
- لا ترفع كلمات المرور الحقيقية أو مفاتيح API أو ملفات الإعدادات الخاصة أو بيانات المستخدمين الحساسة إلى مستودع عام.
- راجع ملفات SQL قبل تنفيذها، خاصةً الملفات التي تنشئ قواعد البيانات أو الجداول أو تحذفها أو تستبدلها.
- راجع المشروع واختبره قبل استخدامه مع مستخدمين حقيقيين أو بيانات تشغيلية.

## استكشاف الأخطاء وإصلاحها

**خطأ في الاتصال بـ MySQL**
- تأكد من أن MySQL Server يعمل.
- تحقق من المضيف والمنفذ واسم المستخدم وكلمة المرور في إعدادات اتصال التطبيق.
- تأكد من وجود قاعدة البيانات والجداول المطلوبة.

**تعذّر العثور على وحدة Python**
- فعّل البيئة الافتراضية.
- أعد تنفيذ الأمر `pip install -r requirements.txt`.
- تأكد من أن ملف `requirements.txt` يحتوي على الاعتماديات التي يحتاج إليها التطبيق.

**تعذّر تسجيل الدخول بالحساب التجريبي**
- تأكد من وجود سجلات الحسابات التجريبية في قاعدة البيانات.
- تحقق من أن التطبيق يتصل بقاعدة البيانات نفسها التي تحتوي على هذه السجلات.
- تأكد من توافق آلية تجزئة كلمات المرور مع التجزئات المخزنة في قاعدة البيانات.
