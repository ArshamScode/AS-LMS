# AS LMS — نظام إدارة التعلّم

تطبيق مكتبي مبني باستخدام Python لإدارة المقررات التعليمية والواجبات ومتابعة تقدّم الطلاب.

## نبذة عن المشروع

**AS LMS** هو نظام لإدارة التعلّم يعمل كتطبيق مكتبي، ويستخدم Python وTkinter وقاعدة بيانات MySQL. يوفر واجهات منفصلة للمسؤولين والمعلمين والطلاب.

## الميزات

* **لوحة المسؤول:** إدارة المستخدمين والمقررات والتسجيلات والعلاقات بين المعلمين والطلاب.
* **لوحة المعلم:** إدارة الواجبات وتحديد المواعيد النهائية والدرجات ومراجعة التسليمات وتقديم الملاحظات.
* **لوحة الطالب:** عرض الواجبات وإرسال الإجابات أو الملفات ومراجعة الدرجات والملاحظات.
* **قاعدة بيانات MySQL:** تخزين بيانات التطبيق في قاعدة بيانات علائقية.
* **واجهة مكتبية:** واجهة رسومية مبنية باستخدام Tkinter وttk.

## التقنيات المستخدمة

* Python
* Tkinter / ttk
* MySQL
* MySQL Connector/Python

## المتطلبات

* Python 3
* MySQL Server
* حزم Python المطلوبة لتشغيل المشروع

## التشغيل

1. ثبّت Python وMySQL Server.
2. أنشئ قاعدة بيانات التطبيق واضبط إعدادات الاتصال.
3. ثبّت الحزم المطلوبة.
4. اضبط بيانات اتصال قاعدة البيانات محليًا.
5. شغّل التطبيق باستخدام الأمر:

```bash
python main.py
```

سيتم استكمال تعليمات تثبيت قاعدة البيانات وإعدادها ضمن توثيق المشروع.

## ملاحظات أمنية

هذا المشروع مخصص للتعلّم والتطوير. قبل استخدامه مع مستخدمين حقيقيين أو بيانات حساسة، يجب مراجعة إدارة بيانات الاتصال وتخزين كلمات المرور وصلاحيات قاعدة البيانات وآليات التحكم في الوصول.

لا ترفع كلمات المرور الحقيقية أو مفاتيح API أو البيانات الخاصة أو ملف `.env` المحلي إلى مستودع عام.
